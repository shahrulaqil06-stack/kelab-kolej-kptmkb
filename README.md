# Portal Rasmi Kelab & Persatuan — KPTM Kota Bharu

Sistem direktori dan pendaftaran kelab serta persatuan pelajar Kolej Poly-Tech MARA (KPTM) Kota Bharu sesi 2026/2027.

## Ciri-Ciri Utama
- **Direktori Interaktif:** Carian pantas, tapisan mengikut kategori (Sukan, Akademik, Seni & Budaya, Inovasi), dan susunan abjad/terbaharu.
- **Mod Gelap & Terang:** Antara muka responsif dengan sokongan *Dark Mode* & *Light Mode*.
- **Panel Pentadbir:** Penyelaras boleh menambah, mengemas kini, dan memadam rekod kelab secara langsung.
- **Pangkalan Data Masa Nyata:** Dikuasakan oleh Supabase PostgreSQL.

## Teknologi Digunakan
- HTML5, CSS3 & Vanilla JavaScript
- Tailwind CSS (CDN) & Lucide Icons
- Supabase JS SDK
